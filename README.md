# 簡報即戰力：研習網站

網站網址：https://chaifish-teacher.github.io/slideworkshop/

| 檔案 | 用途 | 說明 |
|---|---|---|
| `index.html` | 講者用（完整版） | 研習當天使用，含範例專區（IKEA、McDonald's 學生簡報與影片） |
| `workshop.html` | **分享用** | 內容與完整版相同，但不含範例專區，可以直接分享給學員、老師 |
| `takeaway.html` | 分享用 | 今天的重點、AI 指令、練習連結 |
| `practice.html` | 分享用 | 現場練習區、簡報大改造 12 題、簡報健檢清單 |
| `lab.html` | 分享用 | 手機版練習站 |
| `ex/` | 圖片 | 書籍封面（完整版另含範例簡報截圖） |

分享網址：

- 分享用網站：https://chaifish-teacher.github.io/slideworkshop/workshop.html
- Takeaway：https://chaifish-teacher.github.io/slideworkshop/takeaway.html

- 手機版練習站：https://chaifish-teacher.github.io/slideworkshop/lab.html
